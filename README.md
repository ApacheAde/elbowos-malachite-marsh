# Malachite Marsh

Full-colour Python 3 neon tide-hopper arcade for ElbowOS.

Hop a glowing malachite frog across lanes of neon traffic and floating logs. Reach the far bank, score, and avoid a splash.

**Controls:** ← → / A D to move sideways, ↑ / W / Space to hop forward, ↓ / S to hop back, R to restart.

## Play

```bash
pip install -r requirements.txt
python3 malachite_marsh.py --play
```

## Record a 9:16 reel

```bash
python3 malachite_marsh.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
